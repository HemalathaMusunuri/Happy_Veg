# Happy_Veg
A simple vegetable shopping website developed using HTML, CSS, and JavaScript. It includes a home page, account creation, login, vegetable products, shopping cart, offers, search, and contact page.

## Features

- Home page
- Account Creation
- Login page
- Vegetable products
- Add to Cart
- Shopping Cart
- Increase and decrease quantity
- Automatic total amount calculation
- Remove products from cart
- Search vegetables
- Offers page
- Contact Us page
- Responsive design

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Purpose

This project was created as a student web development project to
practice HTML, CSS, and JavaScript concepts.
